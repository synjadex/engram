# Engram — 项目简介

## 是什么
个人知识/技能网络追踪器。把每个知识节点当作神经元，知识节点之间的关系表示成节点之间的连线，用遗忘曲线计算
可提取性，映射为节点的透明度。目标是保守估计遗忘程度，提醒复习。

## 核心原则
1. 保守估计：无证据时默认按遗忘曲线衰减，不假设用户记住了
2. 永不判定“已掌握”：只显示当前估计可提取性和置信度
3. 用户主权：不强制复习，无惩罚，无连击，允许主动休眠/归档
4. 单用户：没有多用户、权限、登录，就是一个本地工具
5. 可视化是心理镜像：网络图像神经网络，给人“这是我的第二大脑”的感觉

## 技术栈
- Python 3.11
- FastAPI + SQLModel + SQLite
- Cytoscape.js（前端图渲染，CDN 引入）
- FSRS 做遗忘调度
- uvicorn 跑服务

## 当前阶段
第一阶段：跑通最小闭环——手动建节点、连线、记录复习、图渲染

## 代码风格
- 完善的类型注解
- 函数短小，单一职责
- 中文注释可以，变量名英文
- 变量名用蛇形命名，函数方法用小驼峰，类用大驼峰
- 不要过度抽象，先能跑再重构
